# Asset provenance

Stillwild ships original, locally synthesized sound and original vector/canvas artwork. Nothing here is copied from AquaSteps, FinSteps, Forest, Finch, SleepTown, or Pikmin Bloom.

| Asset | Creator | Source | Rights |
| --- | --- | --- | --- |
| Forest and ocean scene renderer | Stillwild / Grok Build | `src/components/stillwild/world-canvas.tsx` | Original procedural drawing. App distribution permitted. Share/export of user scenes permitted (artwork only). |
| Species silhouettes (trees, fish, decorations) | Stillwild / Grok Build | same renderer | Original. No third-party references traced. |
| Ambient mixer (foundation, texture, place) | Stillwild / Grok Build | `src/lib/stillwild/audio.ts` | Original Web Audio synthesis. Composition and recording generated at runtime. In-app mixing, distribution, and user listening permitted. No stems to export. |
| UI type | Fraunces, Figtree | Google Fonts (OFL) | SIL Open Font License. |
| Share card / favicon / X banner | Stillwild brand pass | `public/og.jpg`, `public/x-banner.jpg`, `public/favicon.svg` | Original stills for the Stillwild prototype. |

## What this is not

- Not a third-party recording library.
- Not “copyright-free because it was generated.” Generated images and audio still need a rights trail; this prototype uses original procedural/synthesized work created for this app.
- Not a claim that virtual trees represent real tree planting.

## Production follow-up

Commissioned audio for a native iOS release should have written rights covering composition, recording, editable layers, in-app mixing, App Store distribution, and any promotional or user-sharing uses.
